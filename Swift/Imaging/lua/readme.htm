III. The App call the 'main' function of the lua code with 2 paramenters:

(1) the first paramenter is the measurement object array
(2) the second paramenter is the global information:
(a) unitratio: ratio of meter to current unit, number type, such as 100 means centimeter
(b) unitabbr: abbr of the unit, string type, such as 'cm' means centimeter
(c) resolution: pixel number per meter, number type, such as 1000 means each physical pixel is 0.001 meter
(d) decimal: the number of decimal places

Chinese Simplified(简体中文)

V. 主App调用lua代码中的main函数，带有2个参数:

(1) 参数1是测量对象数组
(2) 参数2是全局信息, 包括:
(a) unitratio: 米和当前单位之间的比值, number类型，如100表示厘米
(b) unitabbr: 当前单位简写, string类型，如cm表示厘米
(c) resolution: 分辨率, 每米的pixel数, number类型, 如1000表示每像素的物理尺寸是0.001米
(d) decimal: 保留小数点位数

VI. dump.lua可以用于打印传入main函数参数的结构
